## 🚀 Getting Started

### 1. Install Dependencies
```bash
cd d:\Asthra2k26\multiverse-symposium
npm install
```

### 2. Start Development
```bash
npm start
```

Open `http://localhost:3000` in your browser

### 3. Customize for Your College
See `CUSTOMIZATION.md` for detailed instructions on:
- Updating college name
- Adding events
- Adding speakers
- Changing colors
- Updating venue info
- Customizing countdown date

### 4. Deploy
```bash
npm run build
```

Then deploy the `build/` folder to your hosting platform.
